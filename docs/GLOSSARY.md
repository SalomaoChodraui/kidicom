# Glossary

Strings are written in English in code and translated to Portuguese in the String Catalog. One name per idea.

| Term (EN) | Termo (PT) | Means | Not |
| --- | --- | --- | --- |
| Study | Exame | One imaging exam of one patient on one date (Study Instance UID) | exam, case, estudo |
| Series | Série | One set of images inside a study, like "Axial 1 mm" | sequence, set |
| Image | Imagem | One DICOM instance, possibly with several frames | slice, file, instance |
| Library | Biblioteca | Kidicom's own folder in Application Support that holds copied files | database, base, store |
| Import | Importar | Add studies from files, folders, or zips to the worklist | add, open, load |
| Copy to Library | Copiar para a Biblioteca | Import by copying the files into the Library | duplicate |
| Keep in Place | Manter no Local | Import by remembering where the files are, without copying | link, reference |
| Offline | Indisponível | A Keep in Place study whose files are no longer where they were | missing, broken |
| Worklist | Lista de Exames | The window that lists every study | database, browser |
| Recently Imported | Importados Recentemente | Studies imported in the last seven days | new, latest |
| Skipped | Ignorados | Files in an import that are not DICOM images (JPG, PDF, system files) | failed, rejected |
